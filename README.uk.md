# Modbus Universal

[English](README.md) | **Українська**

Користувацька інтеграція Home Assistant для **будь-яких** Modbus-пристроїв. Підключення й усі регістри налаштовуються в браузері, без YAML. Під капотом — нова інфраструктура Home Assistant: спільні з'єднання інтеграції `modbus` (`async_get_unit`) і бібліотека [`modbus-connection`](https://home-assistant-libs.github.io/modbus-connection/) (`ManualComponent` — розкладка регістрів, відома лише під час роботи).

## Можливості

- **Підключення:** Modbus TCP, RTU over TCP (прозорі конвертери RS485 → Ethernet/Wi-Fi), послідовний порт RTU/ASCII, Modbus UDP.
- **Один пристрій = один запис** («Налаштування → Пристрої та служби → Додати інтеграцію → Modbus Universal»). Кілька пристроїв на одній шині RS485 або за одним шлюзом автоматично ділять одне з'єднання: запити стають у чергу, а не конкурують.
- **Кожен регістр = підзапис**, який додається кнопкою «+ Додати регістр» на картці пристрою. Регістр можна змінити або видалити там само; об'єкт створюється й видаляється разом із ним.
- **Типи об'єктів:** сенсор, бінарний сенсор, група бітів (один регістр — кілька бінарних сенсорів), вимикач, число (уставки), вибір (значення ↔ режим).
- **Типи даних:** int16/uint16/int32/uint32/int64/uint64/float32/float64, рядки; порядок слів (ABCD/CDAB), перестановка байтів, множник, зсув, окремі біти регістра (читання й запис біта без псування решти), coil і дискретні входи, примусовий запис функцією 16.
- **Швидке опитування окремих регістрів:** перемикач «Швидке опитування» в регістра + «Швидкий інтервал опитування» в параметрах пристрою (наприклад, 0,2 с = 5 разів на секунду). Решта регістрів читається зі звичайним інтервалом; обидва опитування йдуть через одне з'єднання й не заважають одне одному.
- **Стан зв'язку:** кожен пристрій має бінарний сенсор «Зв'язок» (connectivity). Якщо довше за «Втрата зв'язку через» секунд не було жодного успішного читання, він переходить у «Відключено». Атрибут `last_seen` — час останньої відповіді пристрою. Сам сенсор не стає недоступним, тому на нього зручно вішати автоматизації.
- **Перевірочне читання** під час додавання регістра: перед збереженням показується поточне значення.
- **Копіювання карти регістрів** з іншого пристрою (Параметри → «Скопіювати регістри з іншого пристрою»): другий такий самий пристрій налаштовується за хвилину.
- **Групове читання:** сусідні регістри читаються одним запитом. Якщо пристрій відхиляє груповий запит (зазвичай через одну хибну адресу), інтеграція переходить на поштучне читання, тож недоступним стає лише проблемний регістр.
- Нумерація регістрів з 0 або з 1, інтервал опитування, тайм-аут, пауза між запитами, автоматичне перепідключення, діагностика з сирими значеннями.

## Встановлення через HACS

1. HACS → «⋮» (справа вгорі) → **Custom repositories**.
2. Repository: `https://github.com/alx2080/modbus_universal`, Type: **Integration** → **Add**.
3. Знайдіть інтеграцію в HACS → **Download** → перезапустіть Home Assistant.

Нові версії HACS покаже сам, як звичайне оновлення.

## Встановлення вручну

1. Скопіюйте теку `custom_components/modbus_universal` у `config/custom_components/` (або додайте репозиторій у HACS як користувацький).
2. Перезапустіть Home Assistant.
3. «Налаштування → Пристрої та служби → Додати інтеграцію → Modbus Universal».

Підтримувані версії: Home Assistant 2025.8+ (потрібні підзаписи). Спільні з'єднання через `async_get_unit` використовуються, якщо вони є у вашій версії HA; на старіших інтеграція відкриває власне з'єднання.

## Як користуватися

1. Додайте пристрій: тип підключення → адреса/порт → Unit ID. Поле «Адреса перевірочного регістра» можна заповнити, щоб перевірити зв'язок.
2. На сторінці інтеграції біля пристрою натисніть **«+ Додати регістр»**, виберіть тип об'єкта й заповніть адресу, тип даних, масштаб тощо. Увімкніть «Прочитати регістр перед збереженням», щоб одразу побачити значення.
3. Щоб змінити регістр — «⋮ → Змінити регістр»; видалити — «⋮ → Видалити».

Приклади:

| Що | Тип об'єкта | Налаштування |
| --- | --- | --- |
| Температура 215 = 21,5 °C | Сенсор | holding, int16, множник 0.1, °C |
| Лічильник енергії, Wh | Сенсор | input, uint32, порядок CDAB за потреби, state class `total_increasing` |
| Аварія = біт 3 регістра 40 | Бінарний сенсор | holding, адреса 40, біт 3 |
| Реле | Вимикач | coil |
| Режим 0/1/2 | Вибір | holding, `0=Вимк`, `1=Авто`, `2=Нагрів` |

## Обмеження та зауваження

- Якщо той самий пристрій уже налаштовано в YAML-конфігурації `modbus:`, він використовує окреме з'єднання — приберіть його з YAML, щоб не було конкурентних запитів.
- Для core-інтеграцій Home Assistant вимагає виносити роботу з пристроєм в окрему бібліотеку на PyPI; для користувацької інтеграції це не обов'язково, тому шар пристрою лежить у `device.py` (без імпортів HA).
